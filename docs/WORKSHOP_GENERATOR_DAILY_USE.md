# Workshop Generator Daily Use Guide

Production URL: `[PLACEHOLDER_PRODUCTION_URL]`

## What this tool does

This tool helps instructors and curriculum designers create standardized workshop HTML that can be pasted into Canvas LMS.

Use it when you need to:

1. Create a new workshop quickly.
2. Keep workshop page structure consistent.
3. Reuse a workshop saved by another instructor.

## Create a new workshop

1. Open the Workshop Generator page.
2. Fill in workshop title, course, and term.
3. Add overview, objectives, materials, equipment, workflow, and submission requirements.

You can keep entering details section by section. The preview updates as you type.

## Preview the workshop

1. Use the right-side preview panel to review formatting and section order.
2. Confirm the sections are complete before copying.

The preview is read-only. Use the form to make edits.

## Copy HTML into Canvas

1. Click `Copy HTML`.
2. Open Canvas and paste the copied HTML into the target page or assignment.
3. Save in Canvas.

If copy fails, use the HTML panel to manually copy.

## Save to Workshop Commons

1. Click `Save to Workshop Commons`.
2. Keep `Save as new copy` enabled unless you are intentionally updating an existing record.
3. Continue working after save if needed.

Saving requires:

1. Workshop title
2. Course
3. Term

## Find a saved workshop

1. Use the Workshop Commons search panel.
2. Search by title, course, term, tags, or summary text.
3. Click a result to reopen it.

## Use a saved workshop as a starting point

1. Open a workshop from commons.
2. Make your edits in the form.
3. Copy updated HTML.
4. Save as a new copy to keep both versions.

## Term code format

Use:

1. `SPYYYY` (Spring)
2. `SUYYYY` (Summer)
3. `FAYYYY` (Fall)
4. `WIYYYY` (Winter)

Examples:

1. `SP2026`
2. `FA2026`

## What to do if something looks wrong

1. Refresh the page once.
2. Reopen the workshop from commons and try again.
3. If the issue continues, send:
   - screenshot
   - workshop title
   - term code
   - time the issue happened
   to your platform support contact.
