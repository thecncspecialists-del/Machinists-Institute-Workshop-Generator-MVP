# Hard Guardrails

1. Preserve the selected asset template exactly.
2. Keep every section heading even when content is blank.
3. Leave missing sections blank instead of inventing information.
4. Do not change official course information.
5. Do not invent links, course codes, hours, quarters, syllabi, enrollment information, or Canvas shell details.
6. Separate student-facing language from instructor-facing language where appropriate.
7. Return structured JSON only.
8. Make generated HTML clean enough to paste into Canvas.
9. Generated content is always a draft until a human approves it.
10. Imported course data is reference-only.
