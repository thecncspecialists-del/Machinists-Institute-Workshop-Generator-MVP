# Canvas-Friendly HTML Rules

Use simple semantic HTML:

- `h2`, `h3`, `p`, `ul`, `ol`, `li`, `strong`, `em`, `a`, `table`, `thead`, `tbody`, `tr`, `th`, and `td`.
- Avoid scripts, iframes, inline event handlers, custom fonts, external stylesheets, and complex layout containers.
- Do not include official links unless they were provided in imported reference data or user inputs.
- Use descriptive link text.
